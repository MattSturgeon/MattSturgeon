I'm a software engineer and open-source maintainer with extensive Linux experience. I particularly enjoy improving existing codebases, developer tooling, build systems, and automation.

Much of my recent work has been in the **Nix ecosystem**, contributing to projects such as **[nixpkgs](https://github.com/NixOS/nixpkgs)** and **[Nixvim](https://github.com/nix-community/nixvim)**. I'm also a maintainer of [Freecam](https://github.com/MinecraftFreecam/Freecam), where I've focused on build, release, and developer tooling, in addition to general maintenance.

## 🛠️ What I like working on

- Refactoring and reducing technical debt
- Developer tooling and improving developer workflows
- Build and release systems
- CI and automation
- Linux, Nix, and reproducible development environments

## 🚀 Selected projects

### 📷 [Freecam](https://github.com/MinecraftFreecam/Freecam)

A Minecraft Java Edition mod that I became involved with as a contributor and gradually took on a larger maintenance role.

My work has included:
- Maintenance, fixes, [features](https://github.com/MinecraftFreecam/Freecam/pull/69), and keeping the project up to date with new Minecraft releases
- Building and maintaining CI for builds, linting, testing, and releases across many supported versions
- Developing Gradle build plugins and supplementary tooling, including a Kotlin [publishing tool](https://github.com/MinecraftFreecam/Publisher)
- Introducing and maintaining changelogs, contributing docs, [release automation](https://github.com/MinecraftFreecam/Freecam/pull/597), and other DevEx tooling
- Restructuring the codebase to reduce technical debt and improve testability, including [extracting the configuration system](https://github.com/MinecraftFreecam/Freecam/pull/556)

### ⚙️ [Nixvim](https://github.com/nix-community/nixvim)

A Nix-based Neovim configuration framework. I initially contributed modules and small improvements before becoming a more active maintainer, focusing particularly on reducing technical debt and improving project architecture.

My contributions have included module development, refactoring, CI, integration testing, and documentation tooling.

### ❄️ Nix ecosystem

I contribute to several NixOS projects and am a member of the **[nix-formatting](https://github.com/orgs/NixOS/teams/nix-formatting)**, **[nixpkgs-ci](https://github.com/orgs/NixOS/teams/nixpkgs-ci)**, **[nixpkgs-committers](https://github.com/orgs/NixOS/teams/nixpkgs-committers)**, and **[nixvim-committers](https://github.com/orgs/nix-community/teams/nixvim-committers)** teams.

In [Nixpkgs](https://github.com/NixOS/nixpkgs), I maintain a handful of packages and regularly review CI-related changes. I've also contributed fixes and improvements in areas including `__structuredAttrs` support and core `lib` functionality.

Other projects I've contributed to include [Nix](https://github.com/NixOS/nix), [flake-compat](https://github.com/NixOS/flake-compat), [nixpkgs-merge-bot](https://github.com/NixOS/nixpkgs-merge-bot), [Nixfmt](https://github.com/NixOS/nixfmt), [Stylix](https://github.com/nix-community/stylix), and [umu-launcher](https://github.com/Open-Wine-Components/umu-launcher).
